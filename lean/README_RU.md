# Полное доказательство гипотезы 4.1 в Lean

Распакуйте архив, откройте терминал в этой папке и выполните одну команду:

```bash
./build.sh
```

Поддерживаются macOS, GNU/Linux и Linux в Windows WSL. Нужны работающие
Git, curl, tar, Bash и `shasum` либо `sha256sum`, а при первом запуске —
интернет. В macOS для работы Git может потребоваться установка Command
Line Tools. Lean и Mathlib отдельно устанавливать не нужно: скрипт сам
подготовит закреплённые версии. Если менеджера Lean ещё нет, он будет
установлен внутри проекта без изменения настроек оболочки.

Первый запуск загружает большие зависимости и может занять значительное
время. Ход проверки показывается по модулям. После полной успешной проверки
появится строка `SUCCESS`, а её запись — в `build-logs/SUCCESS.txt`.
Точные типы итоговых теорем и их аксиомы сохраняются в
`build-logs/final-verification.log`. При ошибке сборка останавливается
и показывает журнал. После устранения причины достаточно повторить
ту же команду.

Архив самодостаточен как проект исходников: ему не нужны
наши прежние сборки или временные папки. Скомпилированных доказательств
проекта в архиве нет; библиотеки загружаются автоматически из публичных
источников. Модули нашего доказательства собираются последовательно.

## Что именно доказано

`Audit41.published_statement` принимает произвольное множество точек
плоскости с четырьмя циклически упорядоченными цветами. Минимальные
расстояния между различными точками равны √2 для одинаковых цветов,
√5 / 2 для соседних цветов и 1 для противоположных.

Из этих условий следуют локальная конечность и исходная оценка гипотезы 4.1:

```text
limsup (r → ∞) #(S ∩ closedBall(0, r)) / (π r²) ≤ 1.
```

Периодичность, локальная конечность и существование предела плотности
не предполагаются. Проверяется вся цепочка доказательства, включая
переход от периодических конфигураций к произвольным.

Обычная сборка включает `Audit41.lean` и `Verification.lean`.
Последний проверяет итоговые теоремы и допускает только стандартные
аксиомы `propext`, `Classical.choice`, `Quot.sound`. Недоказанные
допущения в итоговом результате такую проверку не проходят.

Версии: Lean 4.28.0 и Mathlib
`8f9d9cff6bd728b17a24e163c9402775d9e6a365`.
Все зависимости закреплены в `lake-manifest.json`; обновлять его
командой `lake update` для воспроизведения не нужно.

Этот архив доказывает верхнюю оценку гипотезы 4.1. Дополнительные
результаты статьи о достижимости плотности 1 на целочисленной решётке,
локальных случаях равенства, явных конечных поправках, переносе плотности
в пять измерений и отождествлении с D5 не формализованы в этом проекте.
